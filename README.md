## 📊 Project: Social Media & Mental Health Analysis

Analysis of the impact of social media usage on mental health using a real dataset (Kaggle).

### 🔍 Objectives

* Understand the relationship between screen time, stress, sleep, and well-being
* Identify user profiles using data science techniques

### ⚙️ Methods Used

* Data Cleaning & Preprocessing
* Exploratory Data Analysis (EDA)
* Principal Component Analysis (PCA)
* Clustering (K-Means & Hierarchical)

### 📈 Results

* Identified correlation between high screen time and increased stress
* Highlighted impact of physical activity on well-being
* Detected different user profiles (balanced vs high-risk users)
